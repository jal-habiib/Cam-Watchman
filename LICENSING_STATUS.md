# Licensing status

No project-wide licence is granted by this repository snapshot. Until a licence is selected and third-party dependency/model obligations are reviewed, all rights in the project source are reserved by their respective rights holders. Do not assume this repository is open source or that redistribution is permitted.

The current dependency stack includes components with differing licences. Development notes identify vlcj as GPL-licensed and the currently used YOLO-family model weights as potentially AGPL-licensed, while FFmpeg/JavaCV, JavaFX, ONNX Runtime, SQLite and logging dependencies have their own notices and conditions. Exact versions, model provenance, bundled-vs-system components and distribution obligations must be revalidated against the artefacts actually shipped.

Before external distribution:
- choose and add an explicit project licence;
- verify every dependency and model licence against exact versions and artefacts;
- include required third-party notices and source/relink materials;
- decide whether to replace copyleft model or display components or distribute under compatible terms;
- obtain qualified legal review where appropriate.

This note is informational and is not legal advice.
